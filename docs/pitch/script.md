# 발표 대본 (5분 · 슬라이드 9장 + 라이브 시연 90초)

> 발표 흐름: 슬라이드 1~3 (1분) → **라이브 시연** (1분 30초) → 슬라이드 4~8 (2분) → 슬라이드 9 마무리 (30초)
> 시연은 슬라이드 3 직후. 덱은 `deck.html`(←→ 키) 또는 `deck.pdf`.

## 0:00 — 1. 표지 (15초)
"안녕하세요, 팀 이보배입니다. 오늘 보여드릴 건 「어느 날 내 주식이 전화했다」입니다. 제목 그대로예요. 제 주식이 저한테 전화를 겁니다."

## 0:15 — 2. 문제 (25초)
"주식 앱이 보내는 알림은 이게 전부입니다. 마이너스 6.35퍼센트. 왜 빠졌는지, 내 돈이 얼마 줄었는지는 없어요.
같은 날 올라온 공시 제목은 이렇습니다. '임원·주요주주특정증권등소유상황보고서'. 읽어도 모르니까 아무도 안 읽습니다. 정보는 이미 공개돼 있는데 소비가 안 되는 문제예요."

## 0:40 — 3. 해결 (20초)
"그래서 종목이 직접 전화를 걸게 했습니다. 이건 어제 종가 기준 실제 데이터로 삼성전자가 한 첫 마디예요. (화면 읽지 말고 한 줄만) '형… 나야, 삼성전자… 어제 육 점 삼 퍼센트 빠졌어… 형, 나 버리지 마.'
말로 설명하는 것보다 직접 받아보는 게 빠르죠. 전화 한 통 받겠습니다."

## 1:00 — 라이브 시연 (1분 30초)
1. 삼성전자 카드 → 평단가 210,000원 · 10주 이미 입력돼 있음 → **📞 전화 오게 하기**
   - 벨 울리는 동안: "지금 서버가 Phoenix AI에서 어제 종가, 공시 3건, 3분기 영업이익을 가져오고 있습니다."
2. **받기** → 첫 마디 듣기 (칩 가리키며) "188,700원, 마이너스 6.35퍼센트, **11월 6일 15시 30분 종가 기준**. 토요일이라 장이 닫혔고, 실시간인 척하지 않습니다. 제 수익률 마이너스 10퍼센트도 알고 있네요."
3. 캐릭터가 "공시 하나 냈거든? 들어볼래?" → **"응, 뭔데?"**
4. 공시 사연 듣고 → **"그래서 나 어떡해? 더 사? 팔아?"** → 회피 대사 ("내가 알면 전화 안 하지")
5. **"알았어, 나 바빠. 끊을게."** → "다음에 또 전화할게" → 자동 종료 → 기록 카드 1초 보여주기
   - "방금 들으신 숫자는 전부 카드에 출처와 함께 남습니다. 공시는 DART 원문 링크로."

플랜 B: 마이크 권한 실패 → 통화 화면 "듣기 모드로" (첫 마디 브라우저 음성). Vapi 실패 → "다시 걸기" 1회 후 듣기 모드.

## 2:30 — 4. 데모 흐름 (15초)
"방금 보신 흐름을 정리하면 여섯 단계입니다. 평단은 브라우저에만 저장되고 서버로 가지 않습니다."

## 2:45 — 5. 기분 엔진 (30초)
"핵심은 기분입니다. 등락률로 다섯 단계를 정합니다. 마이너스 3퍼센트 밑이면 오열, 플러스 3퍼센트 위면 기고만장해서 고기 사달라고 합니다.
이건 LLM이 정하지 않습니다. 결정적 로직이라 같은 데이터면 같은 반응이에요. 평단을 넣으면 '형 나 산 거 후회하지?'까지 합니다. 호칭은 형·누나·언니·오빠, 조사까지 자동으로 붙습니다."

## 3:15 — 6. 데이터 정직성 (30초)
"웃기지만 숫자는 한 자리도 지어내지 않습니다. 시세·공시·재무 세 엔드포인트를 서버에서만 부르고, Zod로 검증하고, 기준 시각을 그대로 말합니다. 못 받은 데이터는 캐릭터가 아예 입에 올리지 않아요.
실측 대화입니다. '더 사? 팔아?' 하니까 '내가 알면 전화 안 하지'. 투자 권유 금지 규칙이 작동합니다."

## 3:45 — 7. 음성 스택 & 발견 (30초)
"음성은 Vapi 임시 assistant에 종목 데이터와 캐릭터를 통화마다 주입합니다. STT는 ElevenLabs Scribe 한국어, TTS는 Azure 한국어.
만들면서 발견한 게 두 개 있어요. TTS가 '6.3퍼센트'를 '식스 포인트 쓰리'로, 188,700원을 '일 팔 팔 칠 영 영'으로 읽습니다. 그래서 숫자를 한글 수사로 바꾸는 변환기를 만들었습니다. '십팔만 팔천칠백 원'. 공시 제목의 가운뎃점도 '우'로 읽어서 치환했고요. 통화는 2분 상한을 3겹으로 걸어 비용을 막았습니다."

## 4:15 — 8. 검증 (15초)
"시연 전에 끝까지 눌러 봤습니다. 타입체크·린트·테스트·빌드 통과, openapi 공식 예제로 스키마 검증, 헤드리스 브라우저로 연결부터 자동 종료까지 실측, 코드 리뷰 9건 반영."

## 4:30 — 9. 다음 (30초)
"다음엔 여러 종목이 한꺼번에 전화합니다. 삼성전자랑 에코프로가 서로 싸우는 그룹콜, 매일 아침 '오늘 전화 올 종목' 알림, 공시 원문 요약 연동.
주식 앱은 전부 숫자를 보여줍니다. 저희는 주식이 형한테 전화를 걸게 했습니다. 감사합니다."

## 예상 질문
- **해외 종목은?** 행사 데이터 범위가 한국 시세만이라 오늘은 KRX 종목. 공시·재무는 미국도 되지만 등락률이 없어 기분을 못 정합니다.
- **환각은?** 숫자·공시는 시스템 프롬프트의 "네 상태" 블록에 있는 것만 말하게 하고, 없는 건 "모른다"로. 첫 마디는 코드가 조립합니다.
- **비용은?** 통화 1회 2분 상한(Vapi 분당 과금). Phoenix는 종목당 5분 캐시, 검색 디바운스.
- **왜 전화인가?** 숫자보다 이야기를 기억하고, 전화는 가장 익숙한 '끊을 수 있는' 형식이라 2분짜리 소비 단위가 됩니다.
